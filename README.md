## About

This is a small project for learning React. It is a data-driven React interface that uses reusable components and props to render pricing plans from a single data file.

The cards are generated by mapping over the plan data in `src/data/data.js`. Each plan is passed into the reusable `Entry` component through props, which keeps the UI easy to update without duplicating card markup.

## What I Practiced

- Building reusable React components
- Passing and spreading props into child components
- Rendering a list from structured data
- Highlighting a featured pricing plan with CSS
- Creating a responsive layout with Vite

## Features

- Basic, Pro, and Enterprise pricing plans
- Responsive layout for smaller screens
- Featured Pro plan styling
- Hover states and responsive card ordering
- Live deployment on Vercel

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

## Project Structure

```text

├── Components/

│   ├── Footer.jsx
│   └── Header.jsx
├── data/

├── App.jsx            # Maps data into Entry components
```
